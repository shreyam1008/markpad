# Bundle Budget

Markpad uses the operating system webview and embeds a production frontend inside one Go binary.

## Current release shape

| Artifact | Current size | Policy |
|---|---:|---:|
| Stripped Linux binary | 10,306,440 bytes (9.83 MiB) | hard ceiling 15 MiB |
| Frontend JavaScript | 1,329,773 bytes (1.27 MiB) raw | avoid unbounded growth |
| Frontend CSS | 69,744 bytes (68.1 KiB) raw | generated by Tailwind |

Sizes were measured from the v0.10.0 release build on 2026-08-20. External-change protection and workspace draft filing add no dependency; compared with the prior recorded build, the stripped binary grew by 94,272 bytes, JavaScript by 8,573 bytes, and CSS by 3,928 bytes.

`node_modules`, Bun, TypeScript, Oxlint, Oxfmt, tests, examples, and source maps are development inputs. They are not embedded in the release.

## Runtime memory

WebKitGTK uses separate application, network, and renderer processes. Use proportional set size (PSS), not summed RSS, because RSS double-counts shared pages.

The operating-system webview is the dominant memory cost. Keep document-specific allocations bounded:

- Editable text reads are capped by the Go boundary.
- Images are capped at 50 MiB.
- Syntax highlighting is skipped for very large content.
- Edit history is capped by state count and total text.
- Saved history is capped at 50 snapshots per document.
- PDF data is not loaded into Markpad.
- Workspace scans include at most 10,000 files, visit at most 100,000 entries, descend at most 32 levels, and accept files no larger than 2 MiB.
- Each workspace search reads at most 64 MiB and returns at most 200 results; it has no persistent index.
- Pre-save source verification stream-hashes at most 10 MiB and stores one SHA-256 digest plus filesystem identity per open saved document.

## Dependency rules

- No Electron, browser engine, runtime CDN, telemetry, or cloud client.
- No component suite or general state-management package.
- Browser packages must be bundled and embedded.
- Import icons statically so unused icons are removed.
- Build tools stay in `devDependencies`.
- Direct package versions stay pinned and `bun.lock` stays committed.

## Release checks

1. Run `make setup` from a clean dependency tree.
2. Run `make check`.
3. Run `make build`.
4. Confirm `dist/markpad` is no larger than 15 MiB.
5. Confirm no production asset references an HTTP URL.
6. Exercise Markdown, code, text, image, and PDF handoff offline.
7. Exercise folder open, `Ctrl+P`, `Ctrl+Shift+F`, match selection, file creation, refresh, and confirmed deletion.
