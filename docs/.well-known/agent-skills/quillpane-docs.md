# Quillpane documentation

Quillpane (formerly Markpad) is a native Go/Wails Markdown notepad and local
folder viewer. It stores notes and recovery data on the user's computer and
does not expose a hosted document API, account system, or remote MCP server.

Read the public [LLM guide](https://quillpane.shreyam1008.com.np/llms.txt),
[architecture](https://quillpane.shreyam1008.com.np/architecture.md), and
[launch guide](https://quillpane.shreyam1008.com.np/launch.md) before giving
installation or file-handling advice. Never imply that a website agent can read
the user's notes; those files stay inside the local desktop application.
