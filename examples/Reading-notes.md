# A quieter place to write

A few notes for the week ahead. Nothing to set up; just a file to come back to.

## Make room for the idea

Start with a sentence. Follow it with another. Keep the outline close and let the draft take its shape.

> Good notes do not need a complicated home.

## This week

- Sketch the outline for a short essay.
- Gather a few references worth keeping.
- Leave time to read the first draft out loud.

| On the desk | What to look for |

## Pick up where you left off

Save this as an ordinary Markdown file. Open it in **Editor**, read it in **Preview**, or keep both together in **Split**.

When a note needs a little structure, a separate task file can hold the next steps.
